# HorizonX Recon Lab

Public preview deployment using the five openly released HorizonX drop demos from https://github.com/Mdx2025/horizonx-drops.

This repository is a deployment configuration, not the full HorizonX platform. The original demos and their licenses remain with their authors.

Render build command:
`git clone --depth 1 https://github.com/Mdx2025/horizonx-drops.git /tmp/horizonx-drops && cp -R /tmp/horizonx-drops/. . && npm install && npm run build`

Publish directory: `dist`.
